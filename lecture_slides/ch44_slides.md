# 幻灯片 5 — 安全监控机制总览

## 四层安全防护

| 层级 | 机制 | 响应时间 | 功能 |
|------|------|---------|------|
| L1 | 碰撞检测 | < 50ms | TTC计算、碰撞预警、HMI告警 |
| L2 | 偏离检测 | < 50ms | 车道偏离预警(LDW)、横向误差监控 |
| L3 | 自动紧急制动(AEB) | < 200ms | 三级制动策略 |
| L4 | 驾驶员接管 | < 1.0s | 控制权安全移交 |

**核心安全回路**：
```
感知输入 → 安全监控 → 冲突检测 → 决策干预 → 执行保护
                                    ↓
                              降级/接管
```

# 幻灯片 6 — 碰撞检测与TTC

## Time-to-Collision 原理

```
                    TTC = d_rel / v_rel
                    ─────────────────

    前方车辆                    本车
  ┌────────┐                ┌────────┐
  │        │    d_rel       │        │
  │  v_obj  │ ←───────────→ │  v_ego  │
  │        │                │        │
  └────────┘                └────────┘

TTC 安全阈值:
  🟢 TTC ≥ 3.0s  → 安全
  🟡 2.0s ≤ TTC < 3.0s → 注意
  🟠 1.0s ≤ TTC < 2.0s → 预警
  🔴 TTC < 1.0s → 危险/紧急制动
```

# 幻灯片 7 — AEB三级制动策略

## 自动紧急制动等级

```
制动强度
  100% ┤                    ╔═══════════╗
       │                    ║ Level 3   ║ ← TTC < 0.8s, 全力制动
   60% ┤           ╔════════╣ 双闪开启  ║
       │           ║ Level 2║ 安全带预紧║
       │           ║ 部分制动╚═══════════╝
   30% ┤  ╔════════╣
       │  ║ Level 1║
       │  ║ 预警   ║
    0% ┼──╨────────┴──────────────────────────→ TTC
       3.0s    2.6s    1.8s    0.8s    0s
```

**AEB控制循环**（50Hz）：
```
1. 读取最小TTC ← 从感知/预测模块
2. 判断TTC等级 → 执行对应制动强度
3. 发布控制指令到 /control/cmd
4. 监控减速效果，调整制动力
```

# 幻灯片 10 — 降级策略

## 四级降级策略

```
  Level 0          Level 1           Level 2            Level 3
  全功能运行       感知降级           规划降级            安全停车
  ┌────────┐      ┌────────┐        ┌────────┐        ┌────────┐
  │ 所有传  │      │仅LiDAR │        │限速30   │        │立即制动 │
  │ 感器正常 │      │Camera  │        │禁止换道 │        │请求救援 │
  │ 全速域  │      │失效    │        │        │        │        │
  └────────┘      └────────┘        └────────┘        └────────┘
      ↑               ↑                ↑                 ↑
      └───────────────┴────────────────┴─────────────────┘
                       降级判定逻辑
              score = f(sensor_status, latency, faults)
```

**降级决策实现**：
```python
def degrade(sensor, latency, faults):
    risk = sum([
        not sensor.camera,
        not sensor.lidar * 2,
        latency > 0.2,
        latency > 0.5,
        faults.localization * 3
    ])
    return [NORMAL, DEGRADED, LIMITED, SAFE_STOP][min(risk // 2, 3)]
```

# 幻灯片 14 — 本章总结

## 关键要点

1. **系统集成**：构建完整的感知→决策→规划→控制闭环，通过ROS2话题/服务/动作统一接口
2. **安全监控**：分层防护（碰撞检测→偏离检测→AEB→接管），TTC为核心安全指标
3. **故障容错**：多类型故障注入 + 四级降级策略，保障系统在失效时安全运行
4. **性能评估**：7大指标（碰撞率、偏离率、速度、Jerk、完成率、延迟、精度）
5. **仿真测试**：基于CARLA ScenarioRunner的覆盖策略 → 回归测试 → 边界用例

> **核心思想**: 自动驾驶系统的安全不是单一模块的责任，而是贯穿整个系统架构的设计原则。
