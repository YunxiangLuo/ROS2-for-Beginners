# 第45章 综合项目：城区自动驾驶

## 45.1 项目目标与场景描述

### 45.1.1 项目目标

本综合项目要求学生综合运用第36~44章所学知识，在CARLA仿真环境中实现一个完整的城区自动驾驶系统。项目面向真实自动驾驶研发流程，涵盖传感器驱动、感知、定位、规划、控制、安全监控六大模块。

**核心目标**：在CARLA Town03地图中，控制自车从起点A（坐标 `[-80, -10, 0]`）自动驾驶至终点B（坐标 `[130, -120, 0]`），全程约1.8km，包含6个红绿灯路口、3处人行横道、动态交通流场景。

### 45.1.2 场景描述

| 要素 | 描述 |
|------|------|
| **地图** | CARLA Town03（城区道路网格，含双向车道、环形交叉口） |
| **天气** | 晴朗正午（默认天气），可选挑战：雨天、黄昏 |
| **交通参与者** | 10~20辆NPC车辆（随机行驶），3~5名NPC行人（随机穿越） |
| **红绿灯** | 6组信号灯，周期15~30秒随机 |
| **起点→终点** | A `[-80, -10, 0]` → B `[130, -120, 0]` |
| **限速** | 30 km/h（城区道路） |
| **自车** | Tesla Model 3（配备传感器套件） |

### 45.1.3 传感器配置

| 传感器类型 | 安装位置 | 参数 |
|-----------|---------|------|
| 前置RGB相机 | 前挡风玻璃 | 1920×1080, 90° FOV |
| 前置深度相机 | 前挡风玻璃 | 1920×1080, 90° FOV |
| 前置语义分割相机 | 前挡风玻璃 | 1920×1080, 90° FOV |
| 4个环视相机 | 前后左右 | 1280×720, 120° FOV |
| 激光雷达 | 车顶 | 32线, 40m范围, 20Hz |
| GNSS | 车顶 | 频率20Hz |
| IMU | 车辆质心 | 加速度/角速度, 100Hz |
| 速度计 | 车轮 | 车速, 里程 |

### 45.2.3 数据流时序

1. 传感器驱动层以20Hz频率采集原始数据并发布
2. 感知模块以10Hz频率处理图像与点云，输出障碍物/车道线/交通灯/占据栅格
3. 定位模块以20Hz频率融合GNSS+IMU+车速，输出高频率位姿估计
4. 规划模块以10Hz频率接收感知+定位结果，生成5秒前瞻轨迹（50个路径点，0.1s间隔）
5. 控制模块以50Hz频率运行，计算油门/刹车/转向控制量
6. 安全监控模块独立运行，以50Hz频率检查碰撞风险，必要时覆盖控制信号

## 45.3 模块分工与接口定义

### 45.3.1 话题接口协议

**传感器数据话题**

| 话题名称 | 消息类型 | 频率 | 说明 |
|---------|---------|------|------|
| `/sensor/camera/rgb/image` | `sensor_msgs/Image` | 20 Hz | 前视RGB图像 |
| `/sensor/camera/depth/image` | `sensor_msgs/Image` | 20 Hz | 前视深度图 |
| `/sensor/lidar/pointcloud` | `sensor_msgs/PointCloud2` | 20 Hz | 32线LiDAR点云 |
| `/sensor/gnss/data` | `sensor_msgs/NavSatFix` | 20 Hz | GPS经纬度 |
| `/sensor/imu/data` | `sensor_msgs/Imu` | 100 Hz | 加速度/角速度 |
| `/sensor/speed` | `std_msgs/Float32` | 50 Hz | 当前车速(m/s) |

| 话题名称 | 消息类型 | 频率 | 说明 |
|---------|---------|------|------|

| `/perception/lane_markers` | 扩展接口（待实现） | 10 Hz | 车道线（左/右边界多项式） |
| `/perception/traffic_lights` | 扩展接口（待实现） | 10 Hz | 交通灯状态（颜色/位置/ID） |

| `/localization/ego_twist` | `geometry_msgs/TwistStamped` | 20 Hz | 自车速度/角速度 |

**规划话题**

| 话题名称 | 消息类型 | 频率 | 说明 |

### 45.3.2 坐标帧约定

| 坐标系 | 原点 | 说明 |
|--------|------|------|
| `map` | 地图原点 | 全局地图坐标系（ENU右手系） |
| `odom` | 自车起始点 | 里程计坐标系 |
| `base_link` | 后轴中心 | 自车本体坐标系（前x左y上z） |
| `camera_front` | 前置相机光心 | 相机坐标系（z向前x向右y向下） |
| `lidar` | LiDAR中心 | LiDAR坐标系 |

帧变换树：
```
map → odom → base_link → camera_front
                       → lidar
                       → gnss_antenna
                       → imu_link
```

### 45.3.3 模块间依赖契约

1. **输入数据保证**：传感器驱动必须在节点启动后2秒内开始发布有效数据
2. **输出频率保证**：每个模块的输出频率不得低于约定值的80%
3. **时间戳规范**：所有消息使用共同的ROS时间戳，数据融合时时间差不得超过100ms
4. **异常处理**：模块检测到输入数据超时（>500ms）时，必须发布诊断警告并保持最后有效输出
5. **坐标系一致性**：所有空间数据必须附带`frame_id`字段，且值与45.3.2节一致

## 45.4 迭代开发流程

### 45.4.1 阶段1：路径跟踪（基础能力）

**目标**：实现从起点到终点的路径跟踪，不处理动态障碍物。

**子任务**：
1. 启动CARLA Town03，配置Tesla Model 3传感器套件
2. 实现传感器驱动节点，验证所有传感器数据正确发布
3. 实现定位节点：GNSS+IMU扩展卡尔曼滤波融合
4. 实现全局路径规划：基于车道中心线的路径生成
5. 实现纯跟踪（Pure Pursuit）横向控制器 + PID纵向控制器
6. 调试PID参数，使车辆在直道跟踪误差<0.3m，弯道<0.5m

**交付物**：
- 车辆能够从A→B平稳行驶
- 平均速度≥15 km/h
- 最大横向误差≤0.5m

### 45.4.2 阶段2：避障（动态能力）

**目标**：在阶段1基础上增加静态和动态障碍物检测与规避。

**子任务**：
1. 实现基于LiDAR的障碍物检测：地面分割→聚类→包围框拟合
2. 实现基于视觉的车道线检测：语义分割→车道线拟合
3. 实现局部占据栅格地图
4. 实现行为规划：车道保持→减速跟随→停车等待→变道绕行
5. 实现运动规划：基于Frenet坐标系的轨迹优化
6. 验证碰撞率=0（包括静态障碍物和动态NPC车辆）

**交付物**：
- 车辆能够避开道路上的静态障碍物
- 车辆能够跟随前方慢速车辆（保持≥2秒跟车时距）
- 碰撞次数=0

### 45.4.3 阶段3：交通灯（交规遵守）

**目标**：在阶段2基础上增加交通灯检测与红绿灯遵守。

**子任务**：
1. 实现基于视觉的交通灯检测：YOLO或颜色分割检测灯色
2. 实现交通灯与车道关联：确定当前车道对应信号灯
3. 实现红灯停车逻辑：提前30m减速，距停止线3~5m准确停车
4. 实现绿灯/黄灯通行逻辑
5. 处理多路口连续交通灯场景

**交付物**：
- 红灯停车率=100%
- 停车位置距停止线<1.0m
- 绿灯通行不犹豫
- 黄灯期间若已过停止线则继续通行

### 45.4.4 阶段4：完整闭环（系统集成）

**目标**：集成所有模块，实现完整的城区自动驾驶闭环。

**子任务**：
1. 集成安全监控模块：碰撞预警、偏离预警、紧急制动
2. 实现系统状态诊断与健康检查
3. 实现完整数据记录：ROS bag录制关键话题
4. 系统鲁棒性测试：传感器降级（模拟某传感器失效）
5. 多场景验证：白天/黄昏/雨天、小/中/大交通流量
6. 性能优化：端到端延迟≤150ms，模块CPU占用优化

**交付物**：
- 完整系统在标准场景下稳定运行
- 所有验收指标达标
- 提交完整的代码、配置文件、启动脚本和测试报告
