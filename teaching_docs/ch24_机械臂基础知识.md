## 24.1 机械臂分类

### 24.1.1 按机械结构分类

机械臂按照机械结构可分为以下几种主要类型：

**关节型（Articulated）机械臂**：

关节型机械臂是最常见的工业机器人类型，由一系列旋转关节串联而成，模拟人类手臂的运动方式。典型的6轴关节型机械臂具有6个自由度，可以在三维空间内实现任意位姿。

```
关节型结构：
  基座 → 腰关节(J1) → 肩关节(J2) → 肘关节(J3) 
  → 腕关节(J4) → 腕关节(J5) → 腕关节(J6) → 末端
```

代表产品：KUKA KR系列、ABB IRB系列、Universal Robots UR系列、Franka Emika Panda。

**直角坐标型（Cartesian/Gantry）机械臂**：

由三个线性滑动关节组成，运动方向相互垂直（X、Y、Z轴），定位精度高但灵活性受限。

**SCARA型机械臂**：

Selective Compliance Assembly Robot Arm，具有两个平行旋转关节和一个线性垂直关节，在水平方向柔顺、垂直方向刚性，特别适合装配作业。

**并联型（Parallel）机械臂**：

采用多个并联连杆驱动一个末端平台，刚度高、速度快、负载能力强，但工作空间较小。典型代表：Delta机器人。

**协作型（Collaborative）机械臂**：

具备力控、碰撞检测和安全保护功能，可在无安全围栏的情况下与人协同工作。代表产品：UR5e、Franka Emika Panda、KUKA LBR iiwa。

### 24.1.2 按应用场景分类

| 分类 | 应用场景 | 特点 |
|------|---------|------|
| 工业机器人 | 焊接、搬运、装配、喷涂 | 高速度、高精度、大负载 |
| 服务机器人 | 家庭服务、医疗辅助 | 轻量化、安全交互 |
| 特种机器人 | 太空、水下、核环境 | 环境适应性强 |
| 教育机器人 | 教学实验、科研 | 开放接口、模块化 |

### 24.1.3 机械臂关键技术指标

1. **自由度（DOF）**：独立的运动轴数量，6自由度可到达空间任意位姿
2. **负载能力**：末端可承载的最大质量
3. **工作空间**：末端可达的空间区域
4. **重复定位精度**：多次回到同一点的精度
5. **最大运动速度**：各关节的最大角速度
6. **防护等级**：IP等级，防尘防水能力

## 24.2 运动学基础

### 24.2.1 位姿描述与齐次变换

在机器人学中，物体的位置和姿态统称为位姿（Pose）。

**位置描述**：使用三维向量 p = [x, y, z]^T 表示。

**姿态描述**：使用旋转矩阵 R ∈ SO(3) 表示，是一个3×3的正交矩阵。

**齐次变换矩阵**：将位置和姿态统一表示为4×4矩阵：

```
    [ R   p ]
T = [ 0   1 ]
```

其中 R 是3×3旋转矩阵，p 是3×1位置向量。

**常用旋转表示方法**：

1. **旋转矩阵**：9个参数，有正交约束
2. **欧拉角**：绕固定轴的三次旋转（如 ZYX），存在万向锁问题
3. **四元数**：4个参数，无奇异性，计算效率高

四元数表示为 q = [w, x, y, z]，其中 w 为实部，满足 w² + x² + y² + z² = 1。

```python
# 四元数与欧拉角转换
from scipy.spatial.transform import Rotation as R
import numpy as np

# 欧拉角 → 四元数
r = R.from_euler('zyx', [0.1, 0.2, 0.3])
quat = r.as_quat()  # [x, y, z, w]

# 四元数 → 旋转矩阵
rot_mat = r.as_matrix()

# 四元数 → 欧拉角
euler = r.as_euler('zyx')
```

### 24.2.2 DH参数建模

Denavit-Hartenberg（DH）参数法是描述串联机器人连杆之间变换关系的标准方法。每个连杆由四个参数定义：

| 参数 | 符号 | 含义 |
|------|------|------|
| 连杆长度 | a_i | 沿X_i轴从Z_i到Z_{i+1}的距离 |
| 连杆扭转 | α_i | 绕X_i轴从Z_i到Z_{i+1}的角度 |
| 关节距离 | d_i | 沿Z_i轴从X_{i-1}到X_i的距离 |
| 关节转角 | θ_i | 绕Z_i轴从X_{i-1}到X_i的角度 |

**标准DH参数法**：

相邻连杆的齐次变换矩阵为：

```
T_i = Rot(z, θ_i) * Trans(z, d_i) * Trans(x, a_i) * Rot(x, α_i)
```

展开为：

```
    [cos(θ_i)  -sin(θ_i)cos(α_i)   sin(θ_i)sin(α_i)   a_i*cos(θ_i)]
    [sin(θ_i)   cos(θ_i)cos(α_i)  -cos(θ_i)sin(α_i)   a_i*sin(θ_i)]
T_i = [0         sin(α_i)           cos(α_i)            d_i         ]
    [0         0                  0                   1            ]
```

**六自由度机械臂DH参数表示示例**：

```python
import numpy as np

# 六自由度机械臂DH参数表
# [a, alpha, d, theta_offset]
dh_params = [
    [0,    0,          0.333,  0],      # J1
    [0,    -np.pi/2,   0,      0],      # J2
    [0,    np.pi/2,    0.316,  0],      # J3
    [0.0825, np.pi/2,  0,      0],      # J4
    [-0.0825, -np.pi/2, 0.384, 0],      # J5
    [0,    np.pi/2,    0,      0],      # J6
]

def dh_transform(a, alpha, d, theta):
    """计算DH参数对应的齐次变换矩阵"""
    ct = np.cos(theta)
    st = np.sin(theta)
    ca = np.cos(alpha)
    sa = np.sin(alpha)

    T = np.array([
        [ct, -st*ca,  st*sa,  a*ct],
        [st,  ct*ca, -ct*sa,  a*st],
        [0,   sa,     ca,     d   ],
        [0,   0,      0,      1   ]
    ])
    return T

def forward_kinematics(dh_params, joint_angles):
    """正运动学：计算末端位姿"""
    T = np.eye(4)
    for i, (a, alpha, d, theta_offset) in enumerate(dh_params):
        theta = joint_angles[i] + theta_offset
        T_i = dh_transform(a, alpha, d, theta)
        T = T @ T_i
    return T

# 示例：计算零位姿的末端位姿
joint_angles = [0, 0, 0, 0, 0, 0]
end_effector_pose = forward_kinematics(dh_params, joint_angles)
print(f"末端位姿矩阵:\n{end_effector_pose}")
```

## 24.3 正运动学与逆运动学

### 24.3.1 正运动学（Forward Kinematics）

正运动学是已知各关节角度，计算末端执行器位姿的过程。

对于串联机械臂，正运动学可以通过依次乘相邻连杆的变换矩阵得到：

```
T_0_n = T_0_1 * T_1_2 * ... * T_{n-1}_n
```

在ROS2中，一般通过robot_state_publisher节点自动发布正运动学计算的TF变换。

### 24.3.2 逆运动学（Inverse Kinematics）

逆运动学是已知末端执行器的目标位姿，求解各关节角度的过程。逆运动学比正运动学复杂得多，主要难点在于：

1. **多解性**：同一末端位姿可能对应多组关节角度
2. **存在性**：某些位姿可能超出机械臂的工作空间
3. **奇异性**：在某些位姿下，雅可比矩阵降秩

**解析解法（Closed-form Solution）**：对于满足Pieper准则（三个相邻关节轴交于一点）的机械臂，可推导出解析解。

**数值解法（Numerical Solution）**：基于迭代优化的通用方法，使用雅可比矩阵的伪逆：

```python
import numpy as np

def numerical_ik(target_pose, dh_params, initial_guess, max_iter=100, tol=1e-4):
    """
    数值逆运动学求解（基于雅可比伪逆法）
    参数:
        target_pose: 目标位姿 (4x4 齐次矩阵)
        dh_params: DH参数表
        initial_guess: 初始关节角度
    返回:
        关节角度
    """
    theta = np.array(initial_guess, dtype=float)

    for iteration in range(max_iter):
        # 正运动学计算当前位姿
        current_pose = forward_kinematics(dh_params, theta)

        # 计算位置误差
        pos_error = target_pose[:3, 3] - current_pose[:3, 3]

        # 计算姿态误差（旋转向量）
        R_current = current_pose[:3, :3]
        R_target = target_pose[:3, :3]
        rot_error = R_current.T @ R_target
        # 从旋转矩阵提取旋转向量
        axis_angle = np.array([
            rot_error[2, 1] - rot_error[1, 2],
            rot_error[0, 2] - rot_error[2, 0],
            rot_error[1, 0] - rot_error[0, 1]
        ]) * 0.5

        error = np.concatenate([pos_error, axis_angle])

        if np.linalg.norm(error) < tol:
            return theta

        # 计算雅可比矩阵（数值方法）
        J = compute_jacobian(theta, dh_params)

        # 伪逆求解关节增量
        J_pinv = np.linalg.pinv(J)
        delta_theta = J_pinv @ error

        theta += delta_theta

        # 关节角度限制
        theta = np.clip(theta, -2*np.pi, 2*np.pi)

    print(f"IK未收敛，最终误差: {np.linalg.norm(error)}")
    return theta

def compute_jacobian(theta, dh_params, eps=1e-6):
    """数值计算雅可比矩阵"""
    n = len(theta)
    J = np.zeros((6, n))
    T_current = forward_kinematics(dh_params, theta)

    for i in range(n):
        theta_plus = theta.copy()
        theta_plus[i] += eps
        T_plus = forward_kinematics(dh_params, theta_plus)

        # 位置雅可比（差分）
        pos_diff = (T_plus[:3, 3] - T_current[:3, 3]) / eps
        J[:3, i] = pos_diff

        # 姿态雅可比（差分）
        R_diff = T_plus[:3, :3] @ T_current[:3, :3].T
        rot_vec = np.array([
            R_diff[2, 1] - R_diff[1, 2],
            R_diff[0, 2] - R_diff[2, 0],
            R_diff[1, 0] - R_diff[0, 1]
        ]) * 0.5 / eps
        J[3:, i] = rot_vec

    return J
```

## 24.4 工作空间分析

### 24.4.1 工作空间定义

机械臂的工作空间（Workspace）是指末端执行器可达的所有空间位置的集合。工作空间分为：

- **可达工作空间**：末端可到达的所有位置
- **灵巧工作空间**：末端可以以任意姿态到达的位置

### 24.4.2 工作空间影响因素

1. **关节运动范围**：各关节的转角限制
2. **连杆尺寸**：连杆长度和偏置
3. **机械结构**：关节类型和布局
4. **自碰撞**：连杆之间的物理干涉

### 24.4.3 工作空间数值计算

通过蒙特卡洛方法可以计算机械臂的工作空间：

```python
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

def compute_workspace(dh_params, joint_limits, num_samples=10000):
    """
    蒙特卡洛法计算机械臂工作空间
    参数:
        dh_params: DH参数表
        joint_limits: 关节角度限制 [[min1,max1], [min2,max2], ...]
        num_samples: 采样点数
    返回:
        末端位置点集
    """
    n_joints = len(dh_params)
    positions = []

    for _ in range(num_samples):
        # 在关节限制内随机采样
        joint_angles = np.array([
            np.random.uniform(low, high)
            for low, high in joint_limits
        ])

        # 正运动学计算末端位置
        T = forward_kinematics(dh_params, joint_angles)
        positions.append(T[:3, 3])

    return np.array(positions)

# 示例：计算机械臂工作空间
joint_limits = [
    [-2.96, 2.96],   # J1
    [-2.09, 2.09],   # J2
    [-2.96, 2.96],   # J3
    [-2.09, 2.09],   # J4
    [-2.96, 2.96],   # J5
    [-2.09, 2.09],   # J6
]

workspace_points = compute_workspace(dh_params, joint_limits, num_samples=5000)

# 可视化工作空间
fig = plt.figure(figsize=(10, 8))
ax = fig.add_subplot(111, projection='3d')
ax.scatter(workspace_points[:, 0],
           workspace_points[:, 1],
           workspace_points[:, 2],
           s=1, alpha=0.5)
ax.set_xlabel('X (m)')
ax.set_ylabel('Y (m)')
ax.set_zlabel('Z (m)')
ax.set_title('机械臂工作空间')
plt.show()
```

## 24.5 ROS2机械臂接口

### 24.5.1 JointState话题

ROS2中使用sensor_msgs/JointState消息发布机械臂的关节状态：

```
sensor_msgs/JointState
  - header
  - name: string[]        # 关节名称列表
  - position: float64[]   # 关节位置（弧度）
  - velocity: float64[]   # 关节速度
  - effort: float64[]     # 关节力矩
```

```python
# 订阅关节状态示例
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import JointState

class JointStateSubscriber(Node):
    def __init__(self):
        super().__init__('joint_state_subscriber')
        self.sub = self.create_subscription(
            JointState, '/joint_states', self.joint_callback, 10)

    def joint_callback(self, msg):
        for i, name in enumerate(msg.name):
            self.get_logger().info(
                f'{name}: {msg.position[i]:.3f} rad')

def main(args=None):
    rclpy.init(args=args)
    node = JointStateSubscriber()
    rclpy.spin(node)
    node.destroy_node()
    rclpy.shutdown()
```

### 24.5.2 TF2坐标变换

TF2是ROS2中的坐标变换管理库，维护一棵坐标变换树。对于机械臂，TF树从base_link到各连杆再到末端执行器。

```python
# TF2监听器示例
import rclpy
from rclpy.node import Node
import tf2_ros
from geometry_msgs.msg import PointStamped

class TF2Listener(Node):
    def __init__(self):
        super().__init__('tf2_listener')
        self.tf_buffer = tf2_ros.Buffer()
        self.tf_listener = tf2_ros.TransformListener(self.tf_buffer, self)
        self.timer = self.create_timer(0.1, self.lookup_transform)

    def lookup_transform(self):
        try:
            # 获取从base_link到末端执行器的变换
            transform = self.tf_buffer.lookup_transform(
                'base_link',
                'tool0',
                rclpy.time.Time(),
                rclpy.duration.Duration(seconds=1.0))
            pos = transform.transform.translation
            self.get_logger().info(
                f'末端位置: ({pos.x:.3f}, {pos.y:.3f}, {pos.z:.3f})')
        except Exception as e:
            self.get_logger().warn(f'TF查询失败: {e}')
```

### 24.5.4 ROS2 Control接口

ROS2 Control是ROS2的机器人硬件控制框架，通过ros2_control功能包实现。机械臂控制器类型包括：

- **JointStateController**：发布关节状态
- **JointTrajectoryController**：执行关节轨迹
- **PositionController**：位置控制

