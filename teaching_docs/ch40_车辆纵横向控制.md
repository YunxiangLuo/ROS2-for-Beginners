## 40.1 PID 控制原理

### 40.1.1 基本定义

PID（比例-积分-微分）控制器是工业控制中最广泛使用的反馈控制算法，其输出由三个分量组成：

$$ u(t) = K_p e(t) + K_i \int_0^t e(\tau)d\tau + K_d \frac{de(t)}{dt} $$

传递函数形式：
$$ G(s) = K_p + \frac{K_i}{s} + K_d s $$

### 40.1.2 P / I / D 项物理意义

| 分量 | 符号 | 物理意义 | 对系统影响 |
|------|------|----------|-----------|
| 比例项 | $K_p$ | 对当前误差做出即时响应 | 增大可减小稳态误差，但过大会引起振荡 |
| 积分项 | $K_i$ | 累积历史误差 | 消除稳态误差，但可能引起积分饱和 |
| 微分项 | $K_d$ | 预测误差变化趋势 | 增加阻尼，改善动态响应，但对噪声敏感 |

**比例项**：输出与当前误差成正比。当系统偏离目标时提供矫正力，但单纯P控制存在稳态误差。

**积分项**：对误差的时间积分。只要有误差存在，积分项就会持续增长，直到消除稳态误差。I项的加入提高了系统类型，使0型系统变为I型系统。

**微分项**：预测误差的变化趋势，起到"提前制动"作用。理想的微分器在实际中不可实现，通常使用带低通滤波的近似：

$$ D(s) = \frac{K_d s}{T_f s + 1} $$

### 40.1.3 参数整定 — Ziegler-Nichols 方法

**方法一：阶跃响应法（开环）**。对被控对象施加阶跃输入，记录S型响应曲线；找到拐点并画出切线，确定滞后时间 $L$ 和时间常数 $T$；随后按下表查表计算参数：

| 控制器 | $K_p$ | $K_i$ | $K_d$ |
|--------|-------|-------|-------|
| P | $T/L$ | — | — |
| PI | $0.9T/L$ | $0.27/L$ | — |
| PID | $1.2T/L$ | $0.6/L$ | $0.6T$ |

**方法二：临界比例法（闭环）**。仅使用P控制，逐渐增大 $K_p$ 直至系统出现等幅振荡；记录此时的临界增益 $K_u$ 和临界振荡周期 $T_u$；再按下表查表计算：

| 控制器 | $K_p$ | $K_i$ | $K_d$ |
|--------|-------|-------|-------|
| P | $0.5K_u$ | — | — |
| PI | $0.45K_u$ | $0.54K_u/T_u$ | — |
| PID | $0.6K_u$ | $1.2K_u/T_u$ | $0.075K_u T_u$ |

### 40.1.4 PID 优缺点

**优点**：结构简单、物理意义明确，无需被控对象的精确模型，鲁棒性强、适应范围广。

**缺点**：采用线性控制律，对强非线性系统效果有限；多变量耦合系统难以解耦；积分饱和问题需要额外处理；参数整定较为依赖经验。

### 40.1.5 官方要点——PID 整定的经典文献：从 Ziegler–Nichols 到继电自整定

本节与本章其余"官方要点"内容综合翻译自 Coulter（1992，CMU）的 Pure Pursuit 技术报告、Thrun 等（2006）的 Stanley 论文、CARLA 官方文档（车辆物理与控制章节）与 Autoware 官方文档（轨迹跟随模块），PID 整定部分参考 Åström & Hägglund《Advanced PID Control》的通行讲法；原文均为英文，此处为中文编译，供课后巩固与进阶阅读。

本章 40.1.3 的 Ziegler–Nichols 方法出自 1942 年的同名论文，其「先找临界增益 K_u 与振荡周期 T_u、再按表取 K_p/K_i/K_d」的流程至今仍是国际控制课程的第一课；但文献共同强调其两个局限：整定结果偏激进（约 1/4 幅值衰减率，超调大），且需让系统真实进入临界振荡，工程上对车辆不友好。Åström & Hägglund 的《Advanced PID Control》给出改进路线——继电反馈自整定（relay auto-tuning），用滞环代替人工调 K_u，以及「设定点加权」与抗积分饱和（anti-windup）等工程技巧，是 40.4.1 手动调参步骤（先 P 后 I 再 D）与 40.4.3 自适应 PID 的理论出处。

## 40.2 纵向控制

### 40.2.1 油门/刹车映射

车辆纵向动力学模型简化为：

$$ m\dot{v} = F_{engine} - F_{brake} - F_{resistance} $$

实际控制中，通常将PID输出的控制量映射为油门和刹车指令：

```python
def throttle_brake_map(control_output, v_current, v_target):
    if control_output >= 0:
        # 加速：control_output ∈ [0, 1] 映射到油门
        throttle = clamp(control_output, 0.0, 1.0)
        brake = 0.0
    else:
        # 减速：control_output ∈ [-1, 0] 映射到刹车
        throttle = 0.0
        brake = clamp(-control_output, 0.0, 1.0)
    return throttle, brake
```

**加速模式**：当目标速度 > 当前速度，误差为正，PID输出正控制量。

**制动模式**：当目标速度 < 当前速度，误差为负，PID输出负控制量。

**滑行模式**：当误差较小时，可设置死区避免油门刹车频繁切换。

### 40.2.2 速度PID控制器

速度控制采用级联结构：

```
目标速度 → [速度PID] → 加速度 → [油门/刹车映射] → 车辆 → 实际速度
                                           ↑
                                   速度传感器反馈
```

**前馈+反馈结构**：
$$
a_{cmd} = \underbrace{K_p e_v + K_i \int e_v dt + K_d \dot{e_v}}_{\text{反馈PID}} + \underbrace{a_{ff}}_{\text{前馈}}
$$

前馈项可基于道路坡度、滚动阻力等模型计算。

### 40.2.3 目标速度跟踪

**平滑速度规划**：从上位计划模块获得到达各路径点的目标速度，使用梯形或S形速度曲线平滑：

```python
def smooth_speed_profile(path, v_max, a_max, jerk_max):
    """
    生成平滑速度剖面
    - 路段间速度切换使用S形曲线
    - 弯道处根据曲率限速
    """
    v_profile = []
    for i in range(len(path)):
        curvature = compute_curvature(path, i)
        v_curvature = v_max / (1 + alpha * curvature)
        v_profile.append(min(v_max, v_curvature))
    return v_profile
```

## 40.3 横向控制

### 40.3.1 Pure Pursuit 算法

Pure Pursuit 是一种基于几何追踪的横向控制方法，其核心思想是：车辆始终朝向一个前方预瞄点运动。

**几何原理**：

```
                   目标路径
      预瞄点  ●——————★——————
           /  \    θ
          /     \
         /  δ    \
        /         \
       /      Ld   \
      ●—————————————
    车辆位置         预瞄距离
```

根据 Ackermann 转向几何，前轮转角 $\delta$ 满足：

$$ \delta = \arctan\left(\frac{2L\sin(\theta)}{L_d}\right) $$

其中 $L$ 为车辆轴距，$L_d$ 为预瞄距离，$\theta$ 为车辆纵轴与预瞄方向的夹角。

**预瞄距离自适应**：

$$ L_d = L_{d0} + k_v \cdot v $$

速度越快，预瞄距离越远，控制越平缓。过大的预瞄距离会导致"切弯"现象。

### 40.3.2 Stanley 控制器

Stanley 控制器由斯坦福大学在 DARPA 挑战赛中提出，考虑航向误差和横向偏移：

$$ \delta = \theta_e + \arctan\left(\frac{k \cdot e}{v + \epsilon}\right) $$

其中 $\theta_e$ 为航向角误差，$e$ 为横向偏移误差，$k$ 为增益系数，$v$ 为纵向速度。

Stanley 控制器相比 Pure Pursuit 具有更好的收敛特性，但在低速时对横向误差较敏感。

### 40.3.3 两种控制器对比

| 特性 | Pure Pursuit | Stanley |
|------|-------------|---------|
| 原理 | 几何追踪 | 航向+横向综合 |
| 速度适应性 | 预瞄距离随速调整 | 内置速度归一化 |
| 弯道性能 | 可能切弯 | 相对更好 |
| 实现复杂度 | 简单 | 中等 |
| 参数 | 预瞄距离 $L_d$ | 增益 $k$ |

### 40.3.4 官方要点——Pure Pursuit 官方出处：前视距离的物理直觉

Coulter 1992 年的 CMU 技术报告《Implementation of the Pure Pursuit Path Tracking Algorithm》是本章 40.3.1 的原始出处：把「车后轴-预瞄点」视作一段圆弧，控制律只求圆弧曲率 δ = 2·L·sin(α)/l_d，前视距离 l_d 是唯一调参自由度。报告的核心结论与国际课程的通行讲法一致：l_d 与速度成正比（常用 l_d = k·v），l_d 过小则高频抖动、过大则切弯内侧（cutting corners）；报告还指出 Pure Pursuit 对「路径离散密度」不敏感但天然有内侧截弯，这与 40.3.3 对比表中「结构简单、弯道跟踪偏内」的结论同源。

### 40.3.5 官方要点——Stanley 控制器与 DARPA 实战：横摆误差项的价值

Thrun 等 2006 年的 Stanley 论文（2005 年 DARPA 越野挑战赛冠军车）给出了与 Pure Pursuit 的关键差异：转向控制律由「航向误差 + 横向误差」两项构成，横向误差项增益与前轮距（wheelbase）相关，即 δ = ψ + arctan(k·e/L)，且在速度升高时对横向误差项去饱和（限幅）以保证稳定——这正是 40.3.2 与 40.3.3 对比表中「Stanley 对横向偏差响应更快、高速更稳」的文献依据。论文还强调工程细节：转向指令要经最大转角速率限幅，并在不同路面摩擦系数下重新标定增益，这些与 40.4.2 性能指标表中「超调量、调节时间、稳态误差」的观测维度一一对应。

## 40.4 PID 参数调优

### 40.4.1 手动调参步骤

手动调参的一般顺序是：先调 $K_p$（从小到大增加，使系统产生响应但不振荡），再加 $K_d$（抑制超调、改善动态响应），后加 $K_i$（消除稳态误差，从较小值开始），最后综合微调，反复迭代直至满足性能指标。

### 40.4.2 性能指标表

| 参数 | 上升时间 | 超调量 | 调节时间 | 稳态误差 |
|------|---------|--------|---------|---------|
| 增大 $K_p$ | 减小 | 增大 | 增大 | 减小 |
| 增大 $K_i$ | 减小 | 增大 | 增大 | 明显减小 |
| 增大 $K_d$ | 影响小 | 减小 | 减小 | 影响小 |

### 40.4.3 自适应PID

**增益调度**：
```python
if v < 5.0:      Kp, Ki, Kd = 1.2, 0.1, 0.3
elif v < 10.0:   Kp, Ki, Kd = 1.0, 0.08, 0.25
else:            Kp, Ki, Kd = 0.8, 0.05, 0.2
```

**模糊PID**：根据误差和误差变化率，通过模糊规则在线调整参数。

### 40.4.4 CARLA 仿真调参

在 CARLA 仿真器中调参的优势在于：无风险、可复现，支持多场景自动化测试，并可录制控制数据用于离线分析。

**工作流**：在 CARLA 中设置直线/弯道/变道场景，运行纵向+横向控制器，采集速度跟踪误差和横向偏差数据，再基于代价函数自动搜索最优参数。

**代价函数示例**：
$$ J = \int (w_1 \cdot e_v^2 + w_2 \cdot e_y^2 + w_3 \cdot \delta^2) dt $$

其中 $e_v$ 为速度误差，$e_y$ 为横向偏差，$\delta$ 为控制量。

### 40.4.5 官方要点——CARLA 车辆物理与 Autoware 轨迹跟随的官方参考

CARLA 官方文档《Vehicle Physics》章节是 40.4.4 CARLA 仿真调参的官方依据：车辆由四轮物理引擎（NVIDIA PhysX）驱动，`set_autopilot` 之外的底层控制走 `CarlaEgoVehicleControl`（throttle/brake/steer 归一化），官方提醒高速度档位下要开启物理子步（sub-stepping）避免控制抖动，并提供 Ackermann 控制器接口做真车一致建模。Autoware 官方文档的轨迹跟随（trajectory_follower）模块则展示了工程级方案：横向用 MPC（Model Predictive Control）而非 Pure Pursuit，纵向用带前馈的 PID 速度控制器，并单独提供 `steer_offset` 标定参数——可作为本章控制器从「教学实现」走向「产品实现」的进阶路线图。
