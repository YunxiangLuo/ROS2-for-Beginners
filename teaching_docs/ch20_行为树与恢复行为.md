## 20.1 行为树基础

### 20.1.1 行为树概述

行为树 (Behavior Tree, BT) 是一种用于控制智能体决策流程的树形结构模型。相比传统的有限状态机 (FSM)，行为树具有更好的模块化、可读性和可扩展性。

**行为树的起源：**
- 最初用于游戏AI（Halo 2, 2005）
- 后被引入机器人领域（Nav2, 2019）
- 现已成为机器人任务编排的标准工具

**行为树 vs 有限状态机：**

| 特性 | 行为树 (BT) | 有限状态机 (FSM) |
|------|------------|-----------------|
| 状态表示 | 树形节点 | 状态图 |
| 控制流 | 显式（树结构） | 隐式（转换条件） |
| 模块化 | 高（节点可独立） | 低（转换耦合） |
| 可重用性 | 节点可跨树重用 | 状态难重用 |
| 调试 | 可视化XML | 日志跟踪 |
| 扩展性 | 添加新节点即可 | 需修改所有转换 |
| 容错 | 自然支持（Fallback） | 需显式设计 |

### 20.1.2 节点类型

行为树包含四种核心节点类型：

**控制节点：**

```
Sequence (→): 
  顺序执行子节点
  - 全部返回SUCCESS → 返回SUCCESS
  - 任一返回FAILURE → 停止并返回FAILURE
  - 常用于"必须全部完成的步骤序列"

Fallback (?):
  尝试子节点（优先选择）
  - 任一返回SUCCESS → 返回SUCCESS
  - 全部返回FAILURE → 返回FAILURE
  - 常用于"尝试多种方法的备选方案"

Parallel (⇉):
  并行执行所有子节点
  - 达到成功阈值 → 返回SUCCESS
  - 达到失败阈值 → 返回FAILURE
  - 常用于"同时执行多项任务"

Decorator (装饰节点):
  修改子节点的行为
  - Inverter: 反转结果
  - Repeater: 重复执行
  - RateController: 控制执行频率
  - Timeout: 超时控制
```

**执行节点：**

```
Action (动作节点):
  执行具体任务
  - 导航、旋转、后退、等待
  - 返回 SUCCESS / FAILURE / RUNNING

Condition (条件节点):
  检查条件
  - 电池电量、障碍物检测、是否到达
  - 返回 SUCCESS / FAILURE（不会返回RUNNING）
```

### 20.1.3 节点状态

行为树节点执行后返回三种状态：

| 状态 | 含义 | 后续处理 |
|------|------|---------|
| SUCCESS | 节点执行成功 | 继续执行下一个节点 |
| FAILURE | 节点执行失败 | 触发Fallback或终止 |
| RUNNING | 节点正在执行 | 下次tick继续执行 |

```
执行示例:
Sequence → Step1(SUCCESS) → Step2(RUNNING) → ...
         → Step1(SUCCESS) → Step2(SUCCESS) → 返回SUCCESS

Fallback → Option1(FAILURE) → Option2(SUCCESS) → 返回SUCCESS
         → Option1(FAILURE) → Option2(FAILURE) → Option3(FAILURE) → 返回FAILURE
```

### 20.2.3 行为树节点连接

```python
import rclpy
from rclpy.node import Node
from nav2_msgs.action import NavigateToPose
from rclpy.action import ActionClient

class BehaviorTreeClient(Node):
    """行为树Action客户端"""
    def __init__(self):
        super().__init__('bt_client')
        
        self.navigate_client = ActionClient(
            self, NavigateToPose, 'navigate_to_pose')
            
        # 检查可用行为树
        self.bt_list_client = self.create_client(
            nav2_msgs/srv/GetBehaviors, '/bt_navigator/get_behavior_tree_list')
            
    def get_available_bt(self) -> list:
        """获取可用的行为树列表"""
        while not self.bt_list_client.wait_for_service(timeout_sec=1.0):
            self.get_logger().info('等待BT列表服务...')
            
        future = self.bt_list_client.call_async(
            nav2_msgs/srv/GetBehaviors.Request())
        rclpy.spin_until_future_complete(self, future)
        return future.result().behaviors.trees
    
    def navigate_with_bt(self, x: float, y: float, yaw: float,
                          bt_file: str = ''):
        """使用指定行为树导航"""
        goal = NavigateToPose.Goal()
        goal.pose.header.frame_id = 'map'
        goal.pose.pose.position.x = x
        goal.pose.pose.position.y = y
        goal.pose.pose.orientation.z = math.sin(yaw / 2.0)
        goal.pose.pose.orientation.w = math.cos(yaw / 2.0)
        
        if bt_file:
            goal.behavior_tree = bt_file
            
        self.navigate_client.wait_for_server()
        self.send_goal_future = self.navigate_client.send_goal_async(
            goal, feedback_callback=self.feedback_callback)
        self.send_goal_future.add_done_callback(
            self.goal_response_callback)
```

## 20.3 恢复行为详解

### 20.3.1 恢复行为概述

当导航过程出现异常时，Nav2会触发恢复行为尝试解决问题：

**恢复行为的触发条件：**
1. 路径规划失败（无可行路径）
2. 路径跟踪失败（被障碍物卡住）
3. 目标不可达（被障碍物包围）
4. 代价地图异常（动态障碍物快速变化）

**默认恢复行为序列：**
```
RecoveryNode（最多重试次数）
├── 主行为（ComputePathToPose / FollowPath）
└── 恢复序列（当主行为失败时）
    ├── Spin（原地旋转）
    ├── Wait（等待）
    ├── BackUp（后退）
    └── ClearEntireCostmap（清除代价地图）
```

### 20.3.2 Spin恢复行为

Spin让机器人原地旋转一定角度，重新感知周围环境：

```python
import rclpy
from rclpy.action import ActionClient
from nav2_msgs.action import Spin
from geometry_msgs.msg import Quaternion
import math

class SpinRecovery:
    """Spin恢复行为"""
    def __init__(self, node):
        self.action_client = ActionClient(node, Spin, '/spin')
        
    def send_spin(self, target_yaw: float = 1.57,
                   time_allowance: float = 5.0) -> bool:
        """
        发送旋转命令
        
        参数:
            target_yaw: 目标旋转角度 (rad)
            time_allowance: 允许执行时间 (s)
        """
        goal = Spin.Goal()
        goal.target.yaw = target_yaw
        goal.time_allowance = rclpy.duration.Duration(
            seconds=time_allowance).to_msg()
        
        self.action_client.wait_for_server()
        future = self.action_client.send_goal_async(goal)
        rclpy.spin_until_future_complete(None, future)
        
        goal_handle = future.result()
        if not goal_handle.accepted:
            return False
            
        result_future = goal_handle.get_result_async()
        rclpy.spin_until_future_complete(None, result_future)
        
        result = result_future.result()
        return result.status == 4  # SUCCEEDED
```

### 20.3.3 BackUp恢复行为

BackUp让机器人沿直线后退一段距离：

```python
from nav2_msgs.action import BackUp

class BackUpRecovery:
    """BackUp恢复行为"""
    def __init__(self, node):
        self.action_client = ActionClient(node, BackUp, '/backup')
        
    def send_backup(self, distance: float = 0.15,
                     speed: float = 0.05) -> bool:
        """
        发送后退命令
        
        参数:
            distance: 后退距离 (m)
            speed: 后退速度 (m/s)
        """
        goal = BackUp.Goal()
        goal.target.x = -distance      # 负值表示后退
        goal.speed = speed
        goal.time_allowance = rclpy.duration.Duration(
            seconds=distance / speed + 1.0).to_msg()
        
        self.action_client.wait_for_server()
        future = self.action_client.send_goal_async(goal)
        rclpy.spin_until_future_complete(None, future)
        
        goal_handle = future.result()
        if not goal_handle.accepted:
            return False
            
        result_future = goal_handle.get_result_async()
        rclpy.spin_until_future_complete(None, result_future)
        
        result = result_future.result()
        return result.status == 4
```

### 20.4.2 Python自定义行为树

```python
import py_trees
import py_trees_ros

class BatteryCheck(py_trees.behaviour.Behaviour):
    """自定义行为：电池电量检查"""
    def __init__(self, name: str = "BatteryCheck",
                 min_level: float = 0.2,
                 topic: str = "/battery_status"):
        super().__init__(name)
        self.min_level = min_level
        self.topic = topic
        self.battery_level = None
        
    def setup(self, **kwargs):
        """设置订阅"""
        self.blackboard = py_trees.blackboard.Blackboard()
        
    def initialise(self):
        """初始化（每次执行时调用）"""
        self.battery_level = self.blackboard.get(self.topic)
        
    def update(self) -> py_trees.common.Status:
        """执行检查"""
        if self.battery_level is None:
            return py_trees.common.Status.FAILURE
            
        if self.battery_level > self.min_level:
            self.logger.info(f'电池电量充足: {self.battery_level:.1%}')
            return py_trees.common.Status.SUCCESS
        else:
            self.logger.warning(f'电池电量不足: {self.battery_level:.1%}')
            return py_trees.common.Status.FAILURE
            
    def terminate(self, new_status):
        """清理"""
        pass


class NavigateToPoseAction(py_trees_ros.actions.ActionClient):
    """导航动作客户端包装"""
    def __init__(self, name: str = "NavigateToPose"):
        super().__init__(
            name=name,
            action_type=NavigateToPose,
            action_name="navigate_to_pose",
            action_goal=NavigateToPose.Goal()
        )


def create_custom_behavior_tree() -> py_trees.trees.BehaviourTree:
    """创建自定义行为树"""
    root = py_trees.composites.Sequence("MainSequence", memory=True)
    
    # 电池检查
    battery_check = BatteryCheck()
    root.add_child(battery_check)
    
    # 导航（带恢复的备选）
    navigation = py_trees.composites.Selector("Navigation", memory=True)
    
    # 正常导航
    normal_nav = py_trees.composites.Sequence("NormalNav", memory=True)
    normal_nav.add_child(NavigateToPoseAction("GoToGoal"))
    
    # 恢复导航（清除代价地图后重试）
    recovery_nav = py_trees.composites.Sequence("RecoveryNav", memory=True)
    recovery_nav.add_child(
        py_trees_ros.actions.ServiceClient(
            name="ClearCostmap",
            service_type=ClearEntireCostmap,
            service_name="/global_costmap/clear_entirely"
        )
    )
    recovery_nav.add_child(NavigateToPoseAction("GoToGoalRetry"))
    
    navigation.add_child(normal_nav)
    navigation.add_child(recovery_nav)
    
    root.add_child(navigation)
    
    return py_trees.trees.BehaviourTree(root)


def run_custom_bt():
    """运行自定义行为树"""
    tree = create_custom_behavior_tree()
    tree.setup(timeout=10)
    
    running = True
    while running:
        tree.tick()
        py_trees.console.log_snapshot_ascii(tree)
        time.sleep(0.1)
```

### 20.5.2 恢复行为策略

```python
class RecoveryStrategy:
    """恢复策略管理器"""
    def __init__(self, node):
        self.node = node
        self.spin_client = ActionClient(node, Spin, '/spin')
        self.backup_client = ActionClient(node, BackUp, '/backup')
        self.recovery_sequence = [
            {'name': 'spin', 'angle': 1.57},
            {'name': 'wait', 'duration': 1.0},
            {'name': 'backup', 'distance': 0.15},
            {'name': 'spin', 'angle': 3.14},
            {'name': 'backup', 'distance': 0.3},
            {'name': 'wait', 'duration': 2.0},
        ]
        self.current_step = 0
        
    def attempt_recovery(self) -> bool:
        """执行恢复序列"""
        for step in self.recovery_sequence:
            success = self._execute_step(step)
            if success:
                self.node.get_logger().info(
                    f'恢复成功: {step["name"]}')
                self.current_step = 0
                return True
                
        self.node.get_logger().error('所有恢复行为失败')
        return False
    
    def _execute_step(self, step: dict) -> bool:
        """执行单个恢复步骤"""
        self.node.get_logger().info(
            f'执行恢复: {step["name"]}')
        
        if step['name'] == 'spin':
            return self._do_spin(step['angle'])
        elif step['name'] == 'backup':
            return self._do_backup(step['distance'])
        elif step['name'] == 'wait':
            return self._do_wait(step['duration'])
            
        return False
    
    def _do_spin(self, angle: float) -> bool:
        goal = Spin.Goal()
        goal.target.yaw = angle
        self.spin_client.wait_for_server()
        future = self.spin_client.send_goal_async(goal)
        # ... (等待结果)
        return True
    
    def _do_backup(self, distance: float) -> bool:
        goal = BackUp.Goal()
        goal.target.x = -distance
        self.backup_client.wait_for_server()
        future = self.backup_client.send_goal_async(goal)
        return True
    
    def _do_wait(self, duration: float) -> bool:
        self.node.get_logger().info(f'等待 {duration}s')
        time.sleep(duration)
        return True
```

### 20.6.2 多机器人调度集成

```python
import rclpy
from rclpy.node import Node
from nav2_msgs.action import NavigateToPose
import yaml

class MultiRobotScheduler(Node):
    """多机器人调度器 - 集成行为树"""
    def __init__(self):
        super().__init__('multi_robot_scheduler')
        
        # 注册机器人客户端
        self.robots = {}
        robot_names = ['robot1', 'robot2', 'robot3']
        for name in robot_names:
            self.robots[name] = ActionClient(
                self, NavigateToPose, f'/{name}/navigate_to_pose')
        
        # 任务队列
        self.task_queue = []
        self.load_tasks('tasks.yaml')
        
    def load_tasks(self, task_file: str):
        """加载任务配置"""
        with open(task_file, 'r') as f:
            tasks = yaml.safe_load(f)
            self.task_queue = tasks['tasks']
            
    def dispatch_task(self, robot_name: str, task: dict):
        """派发任务到机器人"""
        if robot_name not in self.robots:
            return
            
        goal = NavigateToPose.Goal()
        goal.pose.header.frame_id = 'map'
        goal.pose.pose.position.x = task['x']
        goal.pose.pose.position.y = task['y']
        
        # 选择行为树
        if task.get('recovery_strategy') == 'aggressive':
            goal.behavior_tree = 'aggressive_recovery.xml'
        else:
            goal.behavior_tree = 'default_navigation.xml'
            
        client = self.robots[robot_name]
        client.wait_for_server()
        client.send_goal_async(goal)
        
        self.get_logger().info(
            f'派发任务给 {robot_name}: ({task["x"]}, {task["y"]})')
```
