## 17.1 代价地图基本原理

### 17.1.1 什么是代价地图

代价地图 (Costmap) 是导航系统中将物理空间建模为带代价值栅格的核心数据结构。每个栅格（cell）包含一个代价值，表示该位置是否适合机器人通过。

**代价值的含义：**

| 值范围 | 标签 | 含义 |
|--------|------|------|
| 0 | Free (空闲) | 无障碍物，可自由通行 |
| 1-127 | Inscribed (刻划) | 靠近障碍物的区域，代价值随距离增加 |
| 128-253 | Obstacle (障碍物) | 障碍物膨胀区域，不宜通行 |
| 254 | Lethal (致命) | 障碍物占据，不可通行 |
| 255 | Unknown (未知) | 未探索区域 |

**代价地图的作用：**
- 为路径规划提供环境模型
- 编码障碍物信息和安全距离
- 支持动态障碍物实时更新
- 分层架构支持多种信息来源

### 17.1.2 Costmap2D数据结构

```python
import numpy as np
from nav_msgs.msg import OccupancyGrid

class Costmap2D:
    """代价地图数据结构"""
    def __init__(self, width: float, height: float, 
                 resolution: float = 0.05):
        self.resolution = resolution
        self.width = int(width / resolution)
        self.height = int(height / resolution)
        self.origin_x = -width / 2.0
        self.origin_y = -height / 2.0
        
        # 主代价数组 (0-255)
        self.costmap = np.zeros((self.height, self.width), dtype=np.uint8)
        
        # 未知区域初始化为255
        self.costmap[:] = 255
        
    def world_to_grid(self, wx: float, wy: float) -> tuple:
        """世界坐标转栅格坐标"""
        gx = int((wx - self.origin_x) / self.resolution)
        gy = int((wy - self.origin_y) / self.resolution)
        return gx, gy
    
    def grid_to_world(self, gx: int, gy: int) -> tuple:
        """栅格坐标转世界坐标"""
        wx = gx * self.resolution + self.origin_x
        wy = gy * self.resolution + self.origin_y
        return wx, wy
    
    def set_cost(self, wx: float, wy: float, cost: int):
        """设置某点的代价值"""
        gx, gy = self.world_to_grid(wx, wy)
        if 0 <= gx < self.width and 0 <= gy < self.height:
            self.costmap[gy, gx] = np.clip(cost, 0, 255)
    
    def get_cost(self, wx: float, wy: float) -> int:
        """获取某点的代价值"""
        gx, gy = self.world_to_grid(wx, wy)
        if 0 <= gx < self.width and 0 <= gy < self.height:
            return int(self.costmap[gy, gx])
        return 255
    
    def to_occupancy_grid(self) -> OccupancyGrid:
        """转换为ROS OccupancyGrid消息"""
        msg = OccupancyGrid()
        msg.header.frame_id = 'map'
        msg.info.resolution = self.resolution
        msg.info.width = self.width
        msg.info.height = self.height
        msg.info.origin.position.x = self.origin_x
        msg.info.origin.position.y = self.origin_y
        
        # 转换代价为-1,0,100格式
        occ = np.zeros_like(self.costmap, dtype=np.int8)
        occ[self.costmap == 0] = 0        # 空闲
        occ[self.costmap == 255] = -1     # 未知
        occ[self.costmap >= 254] = 100    # 障碍物
        occ[(0 < self.costmap) & (self.costmap < 254)] = 0
        
        msg.data = occ.flatten().tolist()
        return msg
    
    def reset(self):
        """重置代价地图"""
        self.costmap[:] = 255
```

## 17.2 分层代价地图架构

### 17.2.1 分层设计思想

Nav2将代价地图设计为分层架构，每一层负责维护不同的代价信息，最终融合为一张主代价地图：

```
          主代价地图 (Master Costmap)
          ┌────────────────────────┐
          │  融合各层代价信息       │
          │  cost = max(all_layers) │
          └──────────┬─────────────┘
                     │
     ┌───────────────┼───────────────┐
     │               │               │
┌────┴────┐   ┌────┴────┐   ┌─────┴─────┐
│Static   │   │Obstacle │   │ Inflation │
│Layer    │   │Layer    │   │ Layer     │
│静态地图  │   │动态障碍物│   │障碍物膨胀  │
└─────────┘   └─────────┘   └───────────┘
```

**各层功能：**

| 图层 | 插件名称 | 功能 | 更新方式 |
|------|----------|------|---------|
| 静态层 | StaticLayer | 加载预建栅格地图 | 静态加载 |
| 障碍物层 | ObstacleLayer | 传感器实时障碍物检测 | 实时更新 |
| 膨胀层 | InflationLayer | 障碍物膨胀/安全距离 | 计算生成 |
| 体素层 | VoxelLayer | 3D体素障碍物感知 | 实时更新 |
| 范围层 | RangeLayer | 距离传感器更新 | 实时更新 |
| 禁飞层 | KeepoutLayer | 禁止进入区域 | 配置加载 |

### 17.2.2 全局代价地图 vs 局部代价地图

| 特性 | 全局代价地图 (Global Costmap) | 局部代价地图 (Local Costmap) |
|------|------------------------------|------------------------------|
| 坐标系 | map | odom |
| 范围 | 整个已知地图 | 机器人周围滚动窗口 |
| 更新频率 | 低 (1-2 Hz) | 高 (5-10 Hz) |
| 分辨率 | 较高 (0.05m) | 较高 (0.05m) |
| 用途 | 全局路径规划 | 局部路径规划和避障 |
| 图层配置 | static+obstacle+inflation | obstacle+inflation (无static) |

## 17.3 静态层配置

### 17.3.1 静态层作用

静态层 (StaticLayer) 负责加载预先构建的栅格地图，将其代价信息传递给主代价地图。

**静态层的输入：**
- `map` 话题上的OccupancyGrid消息
- 或通过 `map_server` 加载的YAML/PGM地图文件

**静态层的工作流程：**
```
1. 订阅 /map 话题
2. 将地图数据转换为costmap格式
3. 标记已知区域为对应代价
4. 标记未知区域为255
5. 持续监听地图更新
```

### 17.3.2 地图文件格式

```yaml
# office_map.yaml
image: office_map.pgm          # 地图图像文件
resolution: 0.050000           # 地图分辨率 (m/像素)
origin: [-10.0, -10.0, 0.0]   # 地图原点 (x, y, yaw)
negate: 0                      # 是否反转像素值
occupied_thresh: 0.65          # 占据阈值 (>0.65视为障碍物)
free_thresh: 0.196             # 空闲阈值 (<0.196视为空闲)
```

### 17.3.3 地图加载机制

```python
import rclpy
from rclpy.node import Node
from nav_msgs.msg import OccupancyGrid
from nav2_msgs.srv import LoadMap
import yaml

class MapLoader(Node):
    """地图加载管理器"""
    def __init__(self):
        super().__init__('map_loader')
        
        self.map_pub = self.create_publisher(
            OccupancyGrid, '/map', 10, 
            qos_profile=rclpy.qos.QoSProfile(
                depth=1,
                durability=rclpy.qos.DurabilityPolicy.TRANSIENT_LOCAL
            ))
            
        self.load_map_service = self.create_service(
            LoadMap, '/map_server/load_map', self.load_map_callback)
            
    def load_map_from_yaml(self, yaml_path: str) -> OccupancyGrid:
        """从YAML文件加载地图"""
        with open(yaml_path, 'r') as f:
            meta = yaml.safe_load(f)
            
        # 读取PGM图像
        import cv2
        image = cv2.imread(meta['image'], cv2.IMREAD_GRAYSCALE)
        
        height, width = image.shape
        resolution = meta['resolution']
        origin = meta['origin']
        
        # 转换PGM到OccupancyGrid
        msg = OccupancyGrid()
        msg.header.frame_id = 'map'
        msg.info.resolution = resolution
        msg.info.width = width
        msg.info.height = height
        msg.info.origin.position.x = origin[0]
        msg.info.origin.position.y = origin[1]
        
        # 像素值转换 (0=白=空闲, 255=黑=障碍物)
        occupied_thresh = meta.get('occupied_thresh', 0.65)
        free_thresh = meta.get('free_thresh', 0.196)
        negate = meta.get('negate', 0)
        
        data = []
        for row in image:
            for pixel in row:
                if negate:
                    pixel = 255 - pixel
                    
                normalized = pixel / 255.0
                if normalized > occupied_thresh:
                    data.append(100)  # 占据
                elif normalized < free_thresh:
                    data.append(0)    # 空闲
                else:
                    data.append(-1)   # 未知
                    
        msg.data = data
        return msg
    
    def load_map_callback(self, request, response):
        """服务回调：加载地图"""
        try:
            occupancy_grid = self.load_map_from_yaml(request.map_url)
            self.map_pub.publish(occupancy_grid)
            self.get_logger().info(f'地图已加载: {request.map_url}')
            response.result = LoadMap.Response().RESULT_SUCCESS
        except Exception as e:
            self.get_logger().error(f'地图加载失败: {e}')
            response.result = LoadMap.Response().RESULT_UNDEFINED_FAILURE
        return response
```

## 17.4 障碍物层配置

### 17.4.1 障碍物层作用

障碍物层 (ObstacleLayer) 使用传感器数据实时检测动态障碍物并更新代价地图。

**障碍物层的工作流程：**
```
1. 订阅传感器话题 (LaserScan/PointCloud2)
2. 将传感器数据转换到地图坐标系
3. 标记传感器点到代价地图 (marking)
4. 清除传感器路径上的代价 (clearing)
5. 障碍物标记为254 (lethal)
```

### 17.4.3 传感器数据处理

```python
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import LaserScan, PointCloud2
import numpy as np
import sensor_msgs_py.point_cloud2 as pc2

class ObstacleLayerProcessor(Node):
    """障碍物层数据处理节点"""
    def __init__(self):
        super().__init__('obstacle_layer_processor')
        
        self.scan_sub = self.create_subscription(
            LaserScan, '/scan', self.scan_callback, 10)
        self.cloud_sub = self.create_subscription(
            PointCloud2, '/point_cloud', self.cloud_callback, 10)
            
        self.obstacle_map = np.zeros((200, 200), dtype=np.uint8)
        self.resolution = 0.05
        
    def scan_callback(self, msg: LaserScan):
        """处理激光扫描数据"""
        ranges = np.array(msg.ranges)
        angles = np.linspace(msg.angle_min, msg.angle_max, len(ranges))
        
        # 过滤无效点
        valid = (ranges > msg.range_min) & (ranges < msg.range_max)
        valid_ranges = ranges[valid]
        valid_angles = angles[valid]
        
        # 转换为笛卡尔坐标
        x = valid_ranges * np.cos(valid_angles)
        y = valid_ranges * np.sin(valid_angles)
        points = np.column_stack((x, y))
        
        # 标记障碍物 (marking)
        for point in points:
            gx = int(point[0] / self.resolution)
            gy = int(point[1] / self.resolution)
            if 0 <= gx < 200 and 0 <= gy < 200:
                self.obstacle_map[gy, gx] = 254  # lethal
                
        # 清除传感器路径 (clearing)
        for angle, distance in zip(valid_angles, valid_ranges):
            for d in np.arange(0.1, distance, 0.1):
                px = d * np.cos(angle)
                py = d * np.sin(angle)
                gx = int(px / self.resolution)
                gy = int(py / self.resolution)
                if 0 <= gx < 200 and 0 <= gy < 200:
                    # 如果栅格在路径上非障碍物，设为0
                    if self.obstacle_map[gy, gx] != 254:
                        self.obstacle_map[gy, gx] = 0
                        
    def cloud_callback(self, msg: PointCloud2):
        """处理点云数据（3D障碍物投影到2D）"""
        points = pc2.read_points(msg, field_names=("x", "y", "z"), 
                                  skip_nans=True)
        
        for point in points:
            x, y, z = point
            # 只考虑一定高度范围内的障碍物
            if -0.1 < z < 2.0:
                # 投影到2D代价地图
                gx = int(x / self.resolution)
                gy = int(y / self.resolution)
                if 0 <= gx < 200 and 0 <= gy < 200:
                    self.obstacle_map[gy, gx] = 254
```

## 17.5 膨胀层配置

### 17.5.1 膨胀层作用

膨胀层 (InflationLayer) 在障碍物周围生成代价值梯度，使规划器能够生成远离障碍物的安全路径。

**膨胀的数学公式：**
```
if distance < inscribed_radius:
    cost = 254 (lethal)
elif distance < inflation_radius:
    cost = exp(-scaling_factor * (distance - inscribed_radius)) * 253
else:
    cost = 0
```

### 17.5.2 膨胀参数详解

```yaml
inflation_layer:
  plugin: "nav2_costmap_2d::InflationLayer"
  inflation_radius: 0.55        # 膨胀半径 (m)
  cost_scaling_factor: 3.0      # 代价衰减因子
```

**参数说明：**

`inflation_radius`：膨胀半径，决定障碍物的影响范围
- 大半径 → 路径远离障碍物（安全但可能绕路）
- 小半径 → 路径贴近障碍物（高效但有碰撞风险）

`cost_scaling_factor`：代价衰减速度
- 高因子 → 衰减快，只有近距离有高代价
- 低因子 → 衰减慢，影响范围大

```python
import numpy as np

class InflationLayer:
    """膨胀层实现"""
    def __init__(self, inflation_radius: float = 0.55,
                 cost_scaling_factor: float = 3.0,
                 resolution: float = 0.05):
        self.inflation_radius = inflation_radius
        self.cost_scaling_factor = cost_scaling_factor
        self.resolution = resolution
        
        # 预计算膨胀核
        self.inflation_kernel = self._compute_inflation_kernel()
        
    def _compute_inflation_kernel(self) -> np.ndarray:
        """预计算膨胀核（用于快速膨胀）"""
        radius_cells = int(np.ceil(self.inflation_radius / self.resolution))
        size = 2 * radius_cells + 1
        kernel = np.zeros((size, size), dtype=np.float32)
        
        # 刻划半径（等于机器人半径）
        inscribed_radius = 0.22  # 机器人半径
        
        center = radius_cells
        for dy in range(-radius_cells, radius_cells + 1):
            for dx in range(-radius_cells, radius_cells + 1):
                distance = np.sqrt(dx**2 + dy**2) * self.resolution
                
                if distance < inscribed_radius:
                    kernel[center + dy, center + dx] = 254  # lethal
                elif distance < self.inflation_radius:
                    # 指数衰减
                    kernel[center + dy, center + dx] = (
                        np.exp(-self.cost_scaling_factor * 
                               (distance - inscribed_radius)) * 253
                    )
                else:
                    kernel[center + dy, center + dx] = 0
                    
        return kernel
    
    def inflate(self, costmap: np.ndarray) -> np.ndarray:
        """对代价地图执行膨胀"""
        inflated = costmap.copy()
        
        # 找到所有障碍物栅格
        obstacle_cells = np.where(costmap >= 254)
        
        kh, kw = self.inflation_kernel.shape
        kh2, kw2 = kh // 2, kw // 2
        
        for y, x in zip(*obstacle_cells):
            # 确定kernel覆盖范围
            y_start = max(0, y - kh2)
            y_end = min(costmap.shape[0], y + kh2 + 1)
            x_start = max(0, x - kw2)
            x_end = min(costmap.shape[1], x + kw2 + 1)
            
            ky_start = kh2 - (y - y_start)
            ky_end = ky_start + (y_end - y_start)
            kx_start = kw2 - (x - x_start)
            kx_end = kx_start + (x_end - x_start)
            
            # 膨胀操作：取各层最大值
            region = inflated[y_start:y_end, x_start:x_end]
            kernel_region = self.inflation_kernel[
                ky_start:ky_end, kx_start:kx_end
            ]
            
            mask = kernel_region > region
            region[mask] = kernel_region[mask]
            
        return inflated
    
    def compute_cost(self, distance: float) -> float:
        """计算给定距离的代价值"""
        inscribed_radius = 0.22
        
        if distance < inscribed_radius:
            return 254.0
        elif distance < self.inflation_radius:
            cost = (np.exp(-self.cost_scaling_factor * 
                          (distance - inscribed_radius)) * 253)
            return cost
        else:
            return 0.0
```

### 17.6.3 膨胀半径选择

```python
def recommend_inflation_radius(robot_radius: float, 
                                environment_type: str) -> float:
    """
    根据机器人尺寸和环境推荐膨胀半径
    """
    base_radius = robot_radius
    
    if environment_type == 'narrow_corridor':
        # 狭窄走廊：尽量靠近障碍物
        multiplier = 1.5
    elif environment_type == 'open_space':
        # 开阔空间：保持安全距离
        multiplier = 3.0
    elif environment_type == 'warehouse':
        # 仓库：标准设置
        multiplier = 2.0
    elif environment_type == 'office':
        # 办公室：兼顾安全和通过性
        multiplier = 2.5
    else:
        multiplier = 2.0
        
    return base_radius * multiplier
```

### 17.6.5 多图层融合策略

```python
class MasterCostmap:
    """主代价地图：融合各层代价"""
    def __init__(self):
        self.layers = {}
        self.master = None
        
    def add_layer(self, name: str, layer: np.ndarray):
        """添加代价图层"""
        self.layers[name] = layer
        
    def update_master(self) -> np.ndarray:
        """融合所有图层到主代价地图
        
        融合策略：
        1. 取所有层的最大值
        2. 静态层优先级最高（255覆盖一切）
        3. 障碍物层覆盖膨胀层
        """
        if not self.layers:
            return None
            
        # 初始化为所有层中最大的
        self.master = np.zeros_like(
            next(iter(self.layers.values())), dtype=np.uint8
        )
        
        for name, layer in self.layers.items():
            # 逐层取最大值融合
            mask = layer > self.master
            self.master[mask] = layer[mask]
            
        return self.master
    
    def get_cost_at_pose(self, x: float, y: float, 
                          robot_radius: float) -> int:
        """查询机器人占用区域的最高代价"""
        # 检查机器人足迹覆盖的栅格
        gx = int(x / 0.05)
        gy = int(y / 0.05)
        radius_cells = int(robot_radius / 0.05)
        
        max_cost = 0
        for dy in range(-radius_cells, radius_cells + 1):
            for dx in range(-radius_cells, radius_cells + 1):
                if dx*dx + dy*dy <= radius_cells*radius_cells:
                    cx, cy = gx + dx, gy + dy
                    if (0 <= cx < self.master.shape[1] and 
                        0 <= cy < self.master.shape[0]):
                        cost = self.master[cy, cx]
                        max_cost = max(max_cost, cost)
                        
        return max_cost
```

### 17.7.2 代价地图调试工具

```python
import rclpy
from rclpy.node import Node
from nav_msgs.msg import OccupancyGrid
import numpy as np

class CostmapDebugger(Node):
    """代价地图调试工具"""
    def __init__(self):
        super().__init__('costmap_debugger')
        
        self.global_costmap_sub = self.create_subscription(
            OccupancyGrid, '/global_costmap/costmap', 
            self.global_callback, 10)
        self.local_costmap_sub = self.create_subscription(
            OccupancyGrid, '/local_costmap/costmap', 
            self.local_callback, 10)
            
    def analyze_costmap(self, msg: OccupancyGrid, name: str):
        """分析代价地图统计数据"""
        data = np.array(msg.data).reshape(
            msg.info.height, msg.info.width)
        
        total = data.size
        
        lethal = np.sum(data == 100)
        inscribed = np.sum((data > 0) & (data < 100))
        free = np.sum(data == 0)
        unknown = np.sum(data == -1)
        
        self.get_logger().info(
            f'{name}分析: '
            f'致命={lethal/total*100:.1f}%, '
            f'膨胀={inscribed/total*100:.1f}%, '
            f'空闲={free/total*100:.1f}%, '
            f'未知={unknown/total*100:.1f}%'
        )
        
    def global_callback(self, msg):
        self.analyze_costmap(msg, '全局代价地图')
        
    def local_callback(self, msg):
        self.analyze_costmap(msg, '局部代价地图')
```

### 17.7.4 常见问题与解决方案

**问题1：代价地图未更新**
- 检查传感器话题是否发布
- 检查TF变换是否正确
- 检查生命周期节点状态

**问题2：路径穿过障碍物**
- 膨胀半径过小
- cost_scaling_factor过大（衰减太快）
- 障碍物层未正确标记

**问题3：计算性能下降**
- 减小代价地图尺寸
- 降低更新频率
- 增大分辨率（如从0.05改为0.1）
